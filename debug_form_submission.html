🔍 Event Creation Form Debug

❌ Current Issue: "data.password" validation error

This error suggests the wrong form/entity is being validated.

🔧 Debug Steps

  1. Open browser dev tools (F12)
  2. Go to Network tab
  3. Submit the event form
  4. Check the form data being sent
  5. Look for any password fields
What to check:
  • ❓ Form action URL
  • ❓ Form method (POST)
  • ❓ Form field names
  • ❓ CSRF token presence
  • ❓ Any password fields in form data

🎯 Expected Form Fields

Evenement Form should have:
  • ✅ evenement[titre]
  • ✅ evenement[description]
  • ✅ evenement[dateDebut]
  • ✅ evenement[dateFin]
  • ✅ evenement[lieu]
  • ✅ evenement[capaciteMax]
  • ✅ evenement[prix]
  • ✅ evenement[categorie]
  • ✅ evenement[statut]
  • ✅ evenement[tags][]
Should NOT have:
  • ❌ user[password]
  • ❌ registration_form[password]
  • ❌ Any password fields

🔍 Possible Causes

1. Wrong Template

Registration form being used instead of event form

2. Form Inheritance

Event form extending wrong base form

3. Entity Mix-up

User entity being validated instead of Evenement
